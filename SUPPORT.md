# Support

Use [GitHub issues](https://github.com/MaibornWolff/sandbox/issues) for reproducible bugs and feature requests.

Before you open an issue:

1. Update to the latest Sandbox version.
2. Run `sandbox doctor`.
3. Search the documentation and existing issues.
4. Remove credentials and private data from logs.

This project does not provide a guaranteed response time or individual support.

Report security vulnerabilities through the private process in [SECURITY.md](SECURITY.md).
