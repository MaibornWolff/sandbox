# Subagent Reviews

Use this guide only when the user requested subagents or approved the proposal to use them.

- If the requested tools are unavailable, explain the limitation and agree on a fallback with the user.
- Give each reviewer the same scope, comparison base, and relevant guidance and requirements sources.
- Assign distinct perspectives or independent areas. Ensure that the assignments cover all three review perspectives.
- Use one reviewer at a time for sequential reviews. Use concurrent reviewers only for an approved parallel review.
- Keep subagent reviews read-only. Consolidate their findings in the main session before applying fixes.
- Verify reported findings against the code and source documents. Use the shared finding and fix workflow for the final result.
