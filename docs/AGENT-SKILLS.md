# Agent skills

Put shared [agent skills](https://agentskills.io/) in `~/.agents/skills/` on the host.
The configuration generated by `sandbox init` mounts them at:

- `~/.agents/skills/` in the container.
- `~/.claude/skills/` for [Claude Code](https://code.claude.com/docs/en/skills).
- `~/.codex/skills/` for [Codex](https://developers.openai.com/codex/skills/).

Add a skill on the host, then start a new container to make it available.
Keep the corresponding `mounts` entries if you edit the generated configuration.

The agent-specific mounts are read-only.
The parent `~/.agents` mount is read-write by default, so agents can still change shared skills through that path.
Remove it or change it to read-only if you do not want host skill changes.

Skills contain instructions, not a security boundary.
Review shared skills before using them across projects.
